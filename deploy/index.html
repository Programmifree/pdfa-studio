Programmifree PDF/A Studio

Converti documenti PDF in PDF/A-1b, 2b, 3b e altri livelli per l'archiviazione di lungo termine.

100% nel tuo browser — nessun upload, nessuna registrazione
Trascina qui i tuoi PDF oppure clicca per sceglierli — i file restano sul tuo dispositivo
motore non disponibile per questo livello: uso Kura

Validità dimostrata, non presunta. Ogni file convertito viene ricontrollato nel browser con regole allineate a veraPDF (motore Kura) prima che tu lo scarichi. Se scegli Ghostscript come motore di conversione e la verifica non supera, il file viene automaticamente riparato con Kura. Tutto gira come WebAssembly nel tuo dispositivo: Ghostscript 10.06 e Kura (entrambi AGPL-3.0, open source). I PDF criptati o protetti da password non sono supportati.

Funziona anche offline: dopo la prima visita i motori restano sul tuo dispositivo (app installabile).
