Programmifree PDF/A Studio
==========================

Conversione PDF -> PDF/A (livelli 1b, 2b, 2u, 2a, 3b, 3u, 3a, 4, 4f, 4e)
interamente nel browser dell'utente: nessun upload, nessuna registrazione.

Distribuzione
-------------
Questo software e' distribuito sotto licenza GNU AGPL-3.0.
Il codice sorgente completo e' disponibile su:
https://github.com/programmifree/pdfa-studio

Componenti di terze parti inclusi (entrambi AGPL-3.0):
- Ghostscript 10.06.0 (WebAssembly build di @bentopdf/gs-wasm)
  https://github.com/ArtifexSoftware/ghostpdl
  https://github.com/alam00000/bentopdf-gs-wasm
- BentoPDF Kura Engine (kura-pdf-wasm)
  https://github.com/alam00000/bentopdf-kura

Installazione
-------------
Caricare il contenuto di questa cartella in programmifree.com/web/app/pdfa/
Il server deve servire i file .wasm con MIME application/wasm
(comportamento predefinito della maggior parte dei server web).
